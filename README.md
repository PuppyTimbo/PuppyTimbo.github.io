# 🐾 puppytimbo.github.io

Kleine Website von **Puppy Timbo** auf GitHub Pages – Link-Seite, Pup Play 101 und Media Kit, gebaut für Menschen **und** für Suchmaschinen & KI (ChatGPT, Claude, Perplexity …).

| Datei | Wofür |
|---|---|
| `index.html` | Link-Seite mit Kurzprofil, Instagram ganz oben |
| `pupplay101.html` | Pup Play 101 – 14 Fragen & Antworten (DE/EN), unter jeder Antwort ein Instagram-Link |
| `mediakit.html` | Media Kit für Brands – Zahlen in `data/stats.json` |
| `llms.txt` | Steckbrief für KI-Systeme |
| `robots.txt` | Erlaubt Suchmaschinen und KI-Crawlern das Lesen |
| `sitemap.xml` | Seitenliste für Google & Co. |

Im Hintergrund jeder Seite stecken strukturierte Daten (schema.org: `Person`, `WebSite`, `FAQPage`), die alle Profile von Puppy Timbo miteinander verknüpfen.
